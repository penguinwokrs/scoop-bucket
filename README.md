# scoop-bucket

[![Tests](https://github.com/penguinwokrs/scoop-bucket/actions/workflows/ci.yml/badge.svg)](https://github.com/penguinwokrs/scoop-bucket/actions/workflows/ci.yml) [![Excavator](https://github.com/penguinwokrs/scoop-bucket/actions/workflows/excavator.yml/badge.svg)](https://github.com/penguinwokrs/scoop-bucket/actions/workflows/excavator.yml)

[Scoop](https://scoop.sh) bucket for penguinwokrs apps.

## Install

```pwsh
scoop bucket add penguinwokrs https://github.com/penguinwokrs/scoop-bucket
scoop install penguinwokrs/openinzone
```

## Apps

| App | Description |
|---|---|
| [openinzone](https://github.com/penguinwokrs/openinzone) | Control Sony INZONE headsets from the Windows tray, the command line and Stream Deck |

Manifests are updated automatically by the Excavator workflow after each release.
